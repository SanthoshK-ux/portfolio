## 🌟 Highlights & Architecture

- **Clean Light Theme**: Crafted with pure white (`#FFFFFF`) and slate canvas backgrounds (`#F8FAFC`), professional royal tech-blue accents (`#2563EB`), fine hairline borders (`#E2E8F0`), and soft elevation shadows.
- **Hero Data Network Canvas**: Interactive, low-overhead HTML5 canvas rendering flowing data points, connections, and ML model nodes with pause-on-scroll optimization and `prefers-reduced-motion` support.

- **Interactive Project Modal System**: Enterprise-grade modal dialogs providing in-depth analysis for each project: *Problem, Solution, Technology Stack, Key Features, Implementation Architecture, Results, GitHub, and Live Demo*.
- **Interactive ML & AI Pipeline Visualizer**: Step-by-step interactive inspector demonstrating the workflow from *Data → Preprocessing → Analysis → Model → Prediction → Insight*.
- **Authentic Credentials & Experience**: Accurately reflects Santhosh K's background at Ramco Institute of Technology, CodeChef profile (`angel_heart_07`), and verified industry simulations (Tata Group, Simplilearn, Forage, TCS iON, Cisco).
- **Printable & Downloadable Resume (`resume.html`)**: Clean, print-optimized resume view with a dedicated browser preview modal.
- **100% Zero-Dependency**: Pure semantic HTML5, modern CSS3, and vanilla ES6+ JavaScript. No build step required; lightning fast and immediately deployable.

## 🚀 Running Locally

Because this project is built with zero build dependencies, you can open and run it instantly:

### Option 1: Direct File Opening
Double-click `index.html` in File Explorer, or open it in any modern browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Python)
```bash
cd "c:\Users\santh\OneDrive\Documents\Desktop\portfolio"
python -m http.server 3000
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.

### Option 3: Node.js (npx serve)
```bash
npx serve .
```

## 🌐 Free Instant Deployment

### GitHub Pages
1. Initialize a repository inside the portfolio folder:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Premium portfolio for Santhosh K"
   ```
2. Create a repository on GitHub (e.g. `portfolio` or `SanthoshK-ux.github.io`).
3. Push the code:
   ```bash
   git remote add origin https://github.com/SanthoshK-ux/portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. In GitHub repository **Settings** → **Pages**, select branch `main` and root `/`. Your site will be live at `https://SanthoshK-ux.github.io/portfolio`.
